# Sprint 4 · 生产部署与 V1.0 交付

## 目标

Sprint 4 是精简企业内部版本的最后阶段。它不增加业务功能，只把 Sprint 1—3 已完成的素材库、题材定位和题材配置能力转为可部署、可检查、可备份、可恢复、可运维的 v1.0.0。

> 后续产品增强说明：当前 `/genre-map` 已改为从素材的“上传平台 + 平台热度”实时聚合的题材月度趋势图；本文件以下年龄—学历内容仅记录 Sprint 4 当时的历史交付范围。

## 冻结范围

V1.0 只保留：

- `/materials`：企业素材库。
- `/genre-map`：年龄—学历题材定位图和定位数据管理。
- `/settings/modules`：题材模块与功能板块配置。
- `/genres/:slug`：参数化题材页面。
- `/api/*`：上述页面所需 API、健康检查及 API 文档。

固定导航至少包含“素材库”“题材定位图”“题材配置”。根路径 `/` 重定向至 `/materials`。

## 明确排除

Sprint 4 不开发登录、注册、会员、支付、角色权限、多租户、AI 生成、网页采集、剧本项目、人物关系、复杂素材版本、回收站或多人协作。生产网络访问控制不等于应用登录，本阶段也不会以运维需求为由增加账号功能。

## 交付范围

### 1. 正式配置与独立数据目录

- 代码保留在 `D:\文档存储`。
- 正式数据存放于 `D:\script_material_data`，包含 `database`、`storage`、`backups`、`logs` 和 `temp`。
- `APP_ENV=production` 时读取不入库的 `backend/.env.production`。
- 环境示例覆盖数据库、storage、日志、备份、临时目录、前端 dist、上传限制、SQLite 并发和日志轮转配置。
- 启动阶段创建缺失的受控子目录；创建或写入失败立即中止，API 不暴露绝对路径。

### 2. 正式数据库迁移

- 原开发库是生产数据的唯一来源；先计算大小与 SHA-256，再生成带时间戳备份。
- 复制原库到正式数据库目录后，仅对正式副本执行 `alembic upgrade head`。
- 验证 `alembic current`、`alembic check`、`PRAGMA integrity_check`、历史数据数量和中文内容。
- Sprint 3 验收数据库与验收附件只归档，不自动合并或展示。
- 禁止改写历史迁移、`create_all`、无备份迁移和自动清除旧数据。

### 3. 旧素材兼容与只读审计

- 无附件的旧素材继续返回并显示“无附件”。
- 无附件或文件缺失时下载返回明确结果，不能把空路径拼接到 storage 根目录。
- `python -m app.tools.audit_data` 默认只读，报告素材总数、有附件数、无附件旧素材数、记录缺文件数、孤立文件数和定位数据数。
- 审计命令不得自动删除数据库记录或文件。

### 4. 生产前端托管

- `pnpm install --frozen-lockfile` 后完成类型检查、单元测试与构建。
- FastAPI 在生产模式托管 `frontend/dist`；API 路由优先，非 API 路由使用 Vue Router SPA 回退。
- `/assets/*` 使用长期缓存，`index.html` 不长期强缓存。
- `/api/*` 未匹配时返回 API 404，不能返回 `index.html`。
- 正式系统不运行 5173 端口，不依赖硬编码开发地址。

### 5. 运行保障

- `/api/health/ready` 检查数据库、迁移版本、storage 可写性和生产前端。
- `application.log` 与 `error.log` 使用轮转日志；生产 API 不返回堆栈。
- SQLite 启用 `foreign_keys`、busy timeout，并根据配置评估 WAL；Uvicorn 固定单 worker。
- 提供 Windows 环境检查、生产启动和备份脚本。

### 6. 备份恢复

- SQLite 数据库使用 Backup API 生成一致性副本。
- 每个备份包含数据库、storage、`manifest.json` 和 `backup.log`。
- 校验数据库完整性、manifest、数据库哈希与存储文件数量。
- 只有新备份验证成功后才执行保留期清理，默认保留 30 天。
- 恢复必须停止服务、保护现场、验证目标备份，并先恢复到临时目录完成演练。

## 企业内网安全

1. 服务可以监听 `0.0.0.0:8000`，但 Windows 防火墙只允许 Domain/Private 配置文件和指定企业网段。
2. 禁止 Public 配置文件、互联网端口转发、路由器映射、云安全组公网放行或反向代理公网发布。
3. 任何可访问该地址的人都能够上传、修改和删除素材；管理员必须严格控制网络可达范围。
4. 删除仍保留二次确认；物理删除后的恢复依赖备份。

## 自动化与验收

必须保留 Sprint 1—3 全部测试，并增加生产配置、静态托管、readiness、旧素材兼容、审计、备份校验、SQLite 配置和迁移保护测试。测试只能使用临时目录和临时数据库，不能触碰 `D:\script_material_data` 或原开发数据库。

最终验收使用 FastAPI 生产托管方式，覆盖前端路由直接打开与刷新、同源 `/api`、素材上传下载删除、定位数据编辑导入导出、重启持久化、备份验证和恢复到测试目录。局域网访问与防火墙范围需由企业管理员在目标网络实机确认。

## 完成定义

以下事项全部满足后才可发布 v1.0.0：

- 原数据库已备份，正式副本迁移及完整性检查通过。
- 数据审计结果已记录，旧数据数量与中文内容得到确认。
- 前后端测试、TypeScript 检查和生产构建通过。
- FastAPI 静态托管、SPA 回退、API 404 和 readiness 通过。
- 正式备份已生成并验证，且完成一次恢复到临时测试目录的演练。
- 日志、Windows 启动脚本、内网防火墙和每日任务计划说明齐备。
- `docs/RELEASE_CHECKLIST.md` 已逐项复核。
- `.env.production`、数据库、storage、备份、日志和上传文件均未进入版本控制。
