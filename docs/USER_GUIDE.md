# 模块化剧本题材素材库 · 用户使用说明

## 1. 系统入口

系统只在企业内部网络使用。管理员会提供类似以下地址：

```text
http://企业服务器IP:8000/materials
```

主要入口：

- “素材库”：上传、查找、预览、修改、下载和删除文件素材。
- “剧本库”：上传和管理剧本编辑观看素材后完成的剧本。
- “平台热度趋势”：选择上传平台，查看各题材按月份变化的平均热度曲线。
- “素材题材库”：从左侧下拉选择题材，只查看该题材下的参考素材。
- “剧本题材库”：从左侧下拉选择题材，只查看该题材下的完成剧本。
- “题材配置”：左右两栏分别维护素材题材、剧本题材的显示和排序。

本系统没有登录和权限功能。任何能够打开地址的人都可以修改和删除数据，请勿把地址转发到企业外部。

素材库与剧本库彼此独立：素材不会显示在剧本库，剧本也不会混入素材库。两者的操作方式基本一致。

同名题材在两库中共享名称、图标、颜色和启停状态，但可以分别隐藏、显示和排序。进入“题材配置”时，左侧是“素材题材配置”，右侧是“剧本题材配置”；屏幕较窄时会依次上下显示。

删除题材属于永久删除，不进入回收站。只有素材数和剧本数都为 0 的题材才能删除；题材下仍有内容时，系统会阻止操作并提示先转移或删除相关内容。由于题材身份由两库共享，删除成功后会同时从素材题材库和剧本题材库消失。

## 2. 上传剧本

1. 剧本编辑先在“素材库”查阅参考素材。
2. 剧本完成后进入左侧“剧本库”。
3. 点击“上传剧本”，选择题材并填写标题、摘要、上传人、对接项目负责人和标签。
4. 提交后可在剧本库列表中阅读、编辑、下载或删除剧本。

## 3. 上传素材

1. 进入“素材库”。
2. 点击右上角“上传素材”。
3. 拖入文件，或点击选择文件；可一次选择多个文件。
4. 选择“公共题材”和“素材类型”。
5. 必须选择或输入“上传平台”，并填写 0—100 的“平台热度”。
6. 按需填写公共标签、公共来源和说明。
7. 检查待上传文件名及大小，移除误选文件。
8. 点击“上传 N 个文件”。
9. 等待逐文件处理结果。批量上传时，一个文件失败不会取消其他成功文件。

上传成功后，一个文件对应一条素材记录，标题默认使用不含扩展名的原文件名。

### 支持格式和大小

支持：

```text
PDF、DOCX、XLSX、CSV、TXT、Markdown、JPG、JPEG、PNG
```

默认单文件上限为 100MB。管理员可以调整限制；超过限制或扩展名不受支持时，页面会显示该文件的失败原因。

## 4. 查找和筛选素材

筛选条件位于素材库顶部：

- **关键词**：搜索标题、原文件名、说明和来源。
- **题材**：只看某个题材的素材。
- **素材类型**：例如人物设定、剧情桥段、场景参考或研究资料。
- **文件类型**：按 PDF、DOCX、图片、文本等扩展名筛选。
- **上传平台**：只看指定平台上传的素材；可选择已有平台或输入自定义平台。
- **标签**：多个标签使用逗号分隔；多个标签匹配任意一个。
- **来源**：按内容来源筛选。
- **上传时间**：设置开始和结束日期。

填写后点击“应用筛选”。不同筛选条件之间是 AND 关系。页面会以标签形式展示已生效条件；点击“清空筛选”可恢复全部素材。筛选条件会写入浏览器地址，刷新、后退或把当前地址发给同事时可以恢复。

列表右上角可以切换表格/卡片视图，并按最新上传、最早上传、最近更新、标题或文件大小排序。

## 5. 查看与预览

点击素材可打开详情：

- JPG、JPEG、PNG：直接显示图片。
- TXT：直接显示文本。
- Markdown：安全渲染文本内容；文件中的脚本不会执行。
- PDF：在浏览器内嵌显示；浏览器策略不允许时可下载或新窗口打开。
- DOCX、XLSX、CSV：显示文件信息，并提供下载；不提供复杂 Office 在线预览。

上传功能启用前建立的历史素材可能没有附件。此时页面显示“无附件”，不会提供有效下载按钮，也不会影响记录查看。若记录有附件信息但文件已丢失，下载会显示明确错误，请联系管理员执行数据审计并检查备份。

## 6. 下载素材

在素材详情或列表操作区点击“下载”。浏览器会以原文件名保存文件。Office 文件需要使用本机 Word、Excel 或兼容软件打开。

下载只能通过素材记录执行；不要向管理员索要服务器存储路径，也不要尝试拼接文件路径。

## 7. 修改素材信息

1. 打开素材详情。
2. 点击“编辑”。
3. 可修改标题、所属题材、素材类型、上传平台、平台热度、标签、来源和说明。
4. 点击保存，列表会立即刷新。

服务器文件名、存储路径、文件大小和 MIME 类型不可编辑。修改信息不会替换原附件；需要替换附件时，应重新上传新文件并在确认备份后删除旧记录。

## 8. 删除素材

1. 在列表或详情中点击“删除”。
2. 阅读二次确认提示，确认记录与物理附件都会删除。
3. 只有确定不再需要时才继续。

删除为物理删除，不进入业务回收站。重要资料应依赖管理员的每日备份恢复。历史无附件记录删除时只处理数据库记录，不会访问未知文件路径。

## 9. 平台热度趋势

1. 素材上传时填写“上传平台”和“平台热度”。平台热度范围为 0—100，两个字段都必须填写。
2. 进入左侧“平台热度趋势”。页面右上方的平台下拉框会自动列出已经上传过素材的平台，包括自定义平台。
3. 选择例如“抖音”，图中每条平滑曲线代表一种题材。
4. 横轴是素材上传月份，纵轴是该平台、该题材、该月所有有效素材的平台热度平均值。
5. 某题材在某个月没有素材时会显示曲线空档，不会当成热度 0。
6. 鼠标移到数据点上可查看平台、题材、月份、平均热度和素材数量。
7. 点击数据点，或切换到“表格”后点击“查看素材”，会进入同时按该题材和上传平台筛选的素材库。

页面上方的“整体平均热度”按素材数量加权计算。超过 12 个月时，图表底部可以拖动缩放查看不同时间段；右上角可保存图表图片。

如果下拉框中没有某个平台，请先确认至少有一条素材使用了该平台，而且上传平台与平台热度都已填写。平台名称会忽略首尾空格和大小写差异进行汇总。

## 10. 常见错误处理

| 现象 | 处理方式 |
| --- | --- |
| 页面无法打开 | 确认电脑连接企业内网，再联系管理员检查服务和防火墙。 |
| 上传提示格式不支持 | 转换为支持格式，不能只修改文件扩展名。 |
| 上传提示超过大小 | 压缩或拆分文件，或联系管理员确认当前上限。 |
| 批量上传部分失败 | 查看逐文件失败原因；成功项已保存，只重试失败项。 |
| 预览空白 | 尝试下载；PDF 还可能被浏览器安全策略拦截。 |
| 显示“无附件” | 这是上传功能启用前的历史记录；可查看元数据但不能下载。 |
| 下载返回文件不存在 | 停止重复尝试，联系管理员运行审计并检查备份。 |
| 筛选没有结果 | 清空部分条件；不同条件按 AND 匹配。 |
| 平台下拉框为空 | 先上传一条同时填写了上传平台和平台热度的素材。 |
| 趋势图某个月断开 | 该题材在该平台、该月没有有效素材，这是正常的空档。 |
| 页面提示服务不可用 | 记录操作时间和页面，联系管理员查看 readiness 与日志。 |

## 11. 数据安全提醒

- 系统没有登录和应用权限，只有企业网络边界能够限制访问。
- 不上传与业务无关的个人敏感信息、密码、密钥或恶意文件。
- 删除素材会删除实际附件；重要内容先确认已进入可验证备份。
- 发现误删时立即联系管理员，说明大致时间、文件名和题材；不要继续大量上传或删除，以便安全恢复。
