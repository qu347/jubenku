# 模块化剧本题材素材库 · 用户使用说明

## 1. 系统入口

系统只在企业内部网络使用。管理员会提供类似以下地址：

```text
http://企业服务器IP:8000/materials
```

主要入口：

- “素材库”：上传、查找、预览、修改、下载和删除文件素材。
- “题材定位图”：查看年龄—学历气泡图，维护和导入导出定位数据。
- “题材配置”：维护题材模块和功能板块。

本系统没有登录和权限功能。任何能够打开地址的人都可以修改和删除数据，请勿把地址转发到企业外部。

## 2. 上传素材

1. 进入“素材库”。
2. 点击右上角“上传素材”。
3. 拖入文件，或点击选择文件；可一次选择多个文件。
4. 选择“公共题材”和“素材类型”。
5. 按需填写公共标签、公共来源和说明。
6. 检查待上传文件名及大小，移除误选文件。
7. 点击“上传 N 个文件”。
8. 等待逐文件处理结果。批量上传时，一个文件失败不会取消其他成功文件。

上传成功后，一个文件对应一条素材记录，标题默认使用不含扩展名的原文件名。

### 支持格式和大小

支持：

```text
PDF、DOCX、XLSX、CSV、TXT、Markdown、JPG、JPEG、PNG
```

默认单文件上限为 100MB。管理员可以调整限制；超过限制或扩展名不受支持时，页面会显示该文件的失败原因。

## 3. 查找和筛选素材

筛选条件位于素材库顶部：

- **关键词**：搜索标题、原文件名、说明和来源。
- **题材**：只看某个题材的素材。
- **素材类型**：例如人物设定、剧情桥段、场景参考或研究资料。
- **文件类型**：按 PDF、DOCX、图片、文本等扩展名筛选。
- **标签**：多个标签使用逗号分隔；多个标签匹配任意一个。
- **来源**：按内容来源筛选。
- **上传时间**：设置开始和结束日期。

填写后点击“应用筛选”。不同筛选条件之间是 AND 关系。页面会以标签形式展示已生效条件；点击“清空筛选”可恢复全部素材。筛选条件会写入浏览器地址，刷新、后退或把当前地址发给同事时可以恢复。

列表右上角可以切换表格/卡片视图，并按最新上传、最早上传、最近更新、标题或文件大小排序。

## 4. 查看与预览

点击素材可打开详情：

- JPG、JPEG、PNG：直接显示图片。
- TXT：直接显示文本。
- Markdown：安全渲染文本内容；文件中的脚本不会执行。
- PDF：在浏览器内嵌显示；浏览器策略不允许时可下载或新窗口打开。
- DOCX、XLSX、CSV：显示文件信息，并提供下载；不提供复杂 Office 在线预览。

上传功能启用前建立的历史素材可能没有附件。此时页面显示“无附件”，不会提供有效下载按钮，也不会影响记录查看。若记录有附件信息但文件已丢失，下载会显示明确错误，请联系管理员执行数据审计并检查备份。

## 5. 下载素材

在素材详情或列表操作区点击“下载”。浏览器会以原文件名保存文件。Office 文件需要使用本机 Word、Excel 或兼容软件打开。

下载只能通过素材记录执行；不要向管理员索要服务器存储路径，也不要尝试拼接文件路径。

## 6. 修改素材信息

1. 打开素材详情。
2. 点击“编辑”。
3. 可修改标题、所属题材、素材类型、标签、来源和说明。
4. 点击保存，列表会立即刷新。

服务器文件名、存储路径、文件大小和 MIME 类型不可编辑。修改信息不会替换原附件；需要替换附件时，应重新上传新文件并在确认备份后删除旧记录。

## 7. 删除素材

1. 在列表或详情中点击“删除”。
2. 阅读二次确认提示，确认记录与物理附件都会删除。
3. 只有确定不再需要时才继续。

删除为物理删除，不进入业务回收站。重要资料应依赖管理员的每日备份恢复。历史无附件记录删除时只处理数据库记录，不会访问未知文件路径。

## 8. 题材定位图

进入“题材定位图”后，可以在“图表”和“表格”之间切换。筛选项包括题材、平台、频道、周期、年龄层级、学历层级、趋势、是否重点和热度范围。

### 气泡含义

- 横向位置：平均年龄，越向右表示平均年龄越高。
- 纵向位置：学历层级，低学历=1、中学历=2、高学历=3。
- 气泡大小：用户占比，越大表示占比越高。
- 气泡颜色：学历层级。
- 明显描边：重点题材。
- 橙色虚线：当前筛选结果按用户占比加权的平均年龄和平均学历位置。
- 九宫格文字：对应年龄与学历区域中的用户占比合计。

点击气泡可查看平台、频道、周期、热度、趋势、样本量和数据来源。“查看该题材素材”会进入已按该题材筛选的素材库。

## 9. 新增和修改定位数据

### 新增

1. 点击“新增数据”。
2. 选择题材，填写数据平台、频道和数据周期。
3. 填写平均年龄，并选择对应年龄层级。
4. 选择学历层级，填写用户占比、热度、趋势和样本量。
5. 按需设置重点题材、数据来源和备注。
6. 点击“保存并刷新图表”。

数据周期使用 `YYYY-MM` 或 `YYYY-Q1` 等格式。平均年龄范围为 0—100（不含 0），用户占比与热度范围为 0—100，样本量不能为负数。

### 修改与删除

切换到“表格”，或点击气泡打开详情后选择“编辑”。保存后：

- 修改平均年龄会使气泡横向移动。
- 修改学历层级会使气泡纵向移动并改变颜色。
- 修改用户占比会改变气泡大小。

定位数据删除为软删除，但仍须在二次确认后执行。

## 10. 模板、导入与错误行

### 下载模板

1. 点击“下载模板”。
2. 选择“Excel 模板”或“CSV 模板”。
3. 保留固定列名，不要合并表头或新增标题行。

### 导入

1. 按模板逐行填写数据。题材名称必须与系统中的题材完全匹配。
2. 点击“导入数据”，选择 `.xlsx` 或 `.csv`。
3. 点击“开始导入”。
4. 查看成功与失败行数。

每一行独立校验。合法行会保存，错误行不会写入，也不会导致其他合法行回滚。失败明细会显示行号、字段和中文原因；修改源文件后可再次导入失败行。系统不会因导入而自动创建新题材。

## 11. 导出当前筛选结果

1. 先设置题材定位筛选条件并点击“应用筛选”。
2. 点击“导出当前结果”。
3. 选择“导出 Excel”或“导出 CSV”。

导出内容只包含当前筛选结果。CSV 使用兼容 Excel 的 UTF-8 编码，打开后不应出现中文乱码。

## 12. 常见错误处理

| 现象 | 处理方式 |
| --- | --- |
| 页面无法打开 | 确认电脑连接企业内网，再联系管理员检查服务和防火墙。 |
| 上传提示格式不支持 | 转换为支持格式，不能只修改文件扩展名。 |
| 上传提示超过大小 | 压缩或拆分文件，或联系管理员确认当前上限。 |
| 批量上传部分失败 | 查看逐文件失败原因；成功项已保存，只重试失败项。 |
| 预览空白 | 尝试下载；PDF 还可能被浏览器安全策略拦截。 |
| 显示“无附件” | 这是上传功能启用前的历史记录；可查看元数据但不能下载。 |
| 下载返回文件不存在 | 停止重复尝试，联系管理员运行审计并检查备份。 |
| 筛选没有结果 | 清空部分条件；不同条件按 AND 匹配。 |
| Excel 导入失败 | 使用最新模板，检查题材名称、周期格式、数字范围和枚举值。 |
| 页面提示服务不可用 | 记录操作时间和页面，联系管理员查看 readiness 与日志。 |

## 13. 数据安全提醒

- 系统没有登录和应用权限，只有企业网络边界能够限制访问。
- 不上传与业务无关的个人敏感信息、密码、密钥或恶意文件。
- 删除素材会删除实际附件；重要内容先确认已进入可验证备份。
- 发现误删时立即联系管理员，说明大致时间、文件名和题材；不要继续大量上传或删除，以便安全恢复。
