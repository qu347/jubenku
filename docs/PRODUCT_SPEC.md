# 模块化剧本题材素材库 · V1.0 产品规格

> 版本：v1.0.0  
> 状态：企业内部版本范围冻结  
> 最后阶段：Sprint 4（生产部署与运维交付）

## 产品定位

本系统是面向企业内部内容团队的剧本题材素材管理工具。系统以题材模块为组织基础，集中完成文件素材上传与筛选、题材配置、受众定位数据维护，以及年龄—学历题材分布分析。

系统按单一企业内部实例部署，不建设面向公众的账号、交易、生成式 AI 或多人协作平台。V1.0 没有应用登录和权限控制，任何能够访问内网地址的人均可上传、修改和物理删除素材，因此必须依赖企业网络边界、Windows 防火墙和指定网段访问控制。

## 最终产品范围

最终产品只包含以下八项能力：

1. **素材上传与筛选**：上传企业内部文件，维护基础元数据，并按关键词、题材、素材类型、文件类型、标签、来源和时间筛选。
2. **题材模块配置**：动态维护共享题材身份；素材题材库与剧本题材库分别控制导航显示和排序。
3. **年龄—学历题材气泡图**：以平均年龄为横轴、学历层级为纵轴、用户占比为气泡大小，展示题材受众定位。
4. **定位数据管理**：新增、查看、修改、删除、筛选和分页管理题材定位数据。
5. **CSV 和 Excel 导入导出**：为定位数据提供 CSV、Excel 模板下载、逐行导入校验和按筛选条件导出。
6. **企业内部部署**：由 FastAPI 同时托管 API 与前端生产构建，单进程部署于 Windows 企业内网。
7. **数据审计与可恢复备份**：只读审计数据库和文件存储，使用 SQLite Backup API 生成一致性备份并校验 manifest。
8. **运行维护**：提供健康检查、轮转日志、环境检查、数据库迁移、每日备份、恢复演练及上线检查文档。

除以上范围外，不继续扩展其他业务系统能力。

## 明确排除

以下能力不属于当前产品，也不进入后续实现：

- 登录、注册和账号体系。
- 会员、订阅、支付和商业化计费。
- 角色、权限和多租户系统。
- AI 生成、AI 改写或智能推荐。
- 网页抓取、自动采集或第三方内容同步。
- 剧本项目及项目—素材关系。
- 人物关系、故事线或知识图谱。
- 多人协作、评论、审批和实时编辑。
- 复杂版本系统、素材历史版本和版本回滚。
- 独立标签管理后台。
- 复杂回收站。

数据库中已存在但不在当前范围内的旧表或模型可以保留，以维持迁移历史完整性；它们不得形成新的接口、页面或业务依赖。

## 核心业务对象

### 题材模块与功能板块

- 每个题材都是由数据库动态维护的独立模块。
- 每个题材拥有全局唯一的 `slug`；素材内容通过 `/genres/:slug` 访问，剧本内容通过 `/script-genres/:slug` 访问。
- 题材名称、slug、图标、颜色、简介和启停状态由两库共享；`material_visible/script_visible` 与 `material_sort_order/script_sort_order` 独立维护。
- 每个题材拥有可配置的功能板块。
- 功能板块支持启用、停用、排序、重命名和软删除。
- 停用或隐藏不得破坏模块及其关联数据。

### 企业素材

- 一条 `Material` 对应一个上传文件。
- 批量上传时，每个文件单独生成一条素材记录并独立返回处理结果。
- 素材只维护题材、标题、素材类型、说明、简单 JSON 标签、来源和文件信息等基础元数据。
- 当前版本不使用独立 `Tag` 管理、`MaterialVersion`、`MaterialRelation` 或 `ProjectMaterial` 等复杂能力。
- 素材文件保存于后端受控目录，数据库只保存相对路径。
- 上传功能出现前建立的旧素材可以没有附件；此类记录必须显示“无附件”，不提供可用的预览或下载操作，也不得因路径为空而访问文件系统。
- 素材删除为物理删除：删除记录时同步清理受控目录内的附件。重要资料依赖正式备份恢复，不提供业务回收站。

### 题材定位数据

- 复用 `GenreMetric` 保存题材、平台、频道、周期、年龄、学历、占比、热度、趋势、样本量和来源等数据。
- 定位数据支持单条维护、筛选分页、CSV/Excel 逐行导入及导出。
- 气泡图与定位数据表格使用同一后端数据源，不使用前端 Mock 数据。

## 最终前端路由

- `/`：重定向至 `/materials`。
- `/materials`：企业素材库。
- `/scripts`：剧本编辑完成稿管理库。
- `/genre-map`：年龄—学历题材气泡图与定位数据管理。
- `/settings/modules`：题材模块与功能板块配置。
- `/genres/:slug`：素材题材页面。
- `/script-genres/:slug`：剧本题材页面。

新增页面使用 Vue Router 懒加载。左侧固定导航包含“素材库”“剧本库”“题材定位图”“题材配置”；下方分为“素材题材库”和“剧本题材库”两个动态选择器。题材配置在桌面端左右双栏展示，窄屏纵向排列。

素材库用于向剧本编辑提供参考文件，剧本库用于保存剧本编辑查看素材后完成的剧本。两者复用文件管理能力，但通过 `library_type` 分开持久化和查询。生产模式下，上述前端路由及静态资源由 FastAPI 从 `frontend/dist` 提供；`/api/*` 始终优先按 API 路由处理，不得被 SPA 回退接管。

## 正式运行边界

- 应用代码：`D:\文档存储`。
- 正式数据根目录：`D:\script_material_data`，与代码更新相互独立。
- 正式数据库：`D:\script_material_data\database\script_materials.db`。
- 正式附件：`D:\script_material_data\storage\materials\YYYY\MM\`。
- 备份与日志：`D:\script_material_data\backups`、`D:\script_material_data\logs`。
- 生产数据库使用 SQLite，Uvicorn 固定单 worker，并启用外键、合理的 busy timeout；WAL 是否启用由生产配置决定。
- 生产服务可监听 `0.0.0.0:8000`，但只允许 Domain/Private 网络中的企业网段访问，严禁公网端口转发或路由器互联网映射。
- 正式配置保存在不入库的 `backend/.env.production`；仓库仅保留 `backend/.env.production.example`。
- V1.0 不实施 PostgreSQL 迁移；并发规模显著增长时再单独评估迁移。

## 全局业务规则

1. 所有业务数据必须通过后端接口持久化，不得使用 Mock 数据冒充真实功能。
2. 空题材模块允许永久删除；题材下仍有素材或剧本时必须返回 409 并阻止删除。功能板块和定位数据沿用软删除规则；素材与剧本删除同时清理数据库记录和对应物理文件，不建设复杂回收站。
3. 普通查询默认排除已删除数据。
4. URL 查询参数保存素材筛选与定位数据筛选状态，刷新、前进和后退应能恢复筛选。
5. 后端接口统一使用 Pydantic 校验、Service 层、Repository 层、统一异常响应和正确 HTTP 状态码。
6. 文件上传、数据库写入和物理文件操作必须具备失败补偿，不能留下孤立记录或残留文件。
7. Alembic 是唯一正式建表和变更方式，应用启动时不得调用 `create_all`。
8. 不得删除、重写或篡改 Sprint 1、Sprint 2 已提交的迁移。
9. API 响应、健康检查与日志不得泄露数据库、storage 或用户目录的绝对路径，不得记录上传文件正文或环境变量内容。
10. 正式部署前必须先备份、再迁移并执行 SQLite 完整性检查与只读数据审计。
11. 每日备份至少一次，备份只有在数据库完整性、manifest 和存储文件数量验证通过后才视为成功；恢复必须先在临时目录演练。

## 技术基线

- 前端：Vue 3、TypeScript、Vite、Vue Router、Pinia、Element Plus、Apache ECharts、pnpm。
- 后端：Python 3.10、FastAPI、SQLAlchemy 2、Pydantic 2、Alembic、openpyxl。
- 开发数据库：SQLite；正式 V1.0 同样使用 SQLite，通过 `DATABASE_URL` 保留未来切换能力，但本版本不实施 PostgreSQL 迁移。
- 开发文件存储：`backend/storage/materials/YYYY/MM/`；正式文件存储位于独立数据根目录，数据库始终保存相对路径。
- 默认上传限制：100MB，通过 `MAX_UPLOAD_MB` 配置。
- UI：延续深色企业内容平台风格，优先适配 1440px，并兼容 1280px 和 1024px。
- 生产前端：执行 `pnpm run build` 后由 FastAPI 托管，不使用 Vite 开发服务器。
- 运维：Alembic、readiness、轮转日志、数据审计、一致性备份及校验、Windows 任务计划程序。

## 迭代边界

- Sprint 1：后端分层、数据库模型、迁移、基础接口和初始化数据。
- Sprint 2：动态题材导航、参数化题材页面、题材模块设置和功能板块设置。
- Sprint 3：精简后的核心业务阶段，交付企业素材上传与筛选、题材定位数据管理、CSV/Excel 导入导出和年龄—学历题材气泡图。
- Sprint 4：冻结 V1.0 业务范围，交付正式数据切换、生产静态托管、健康与日志、数据审计、备份恢复、Windows 部署脚本及最终验收；不增加业务功能。
