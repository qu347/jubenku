# 素材平台热度与题材定位图精简设计

## 1. 目标

素材上传人员在素材库上传文件时补充“上传平台”和“平台热度”。系统不再要求用户单独维护年龄、学历等题材定位数据，而是直接根据素材记录，按“题材 + 上传平台”实时汇总题材定位结果。

本次仅调整素材库与题材定位图。剧本库不要求填写平台信息。

## 2. 已确认的业务口径

- 上传平台：必填，提供常用平台选项，同时允许输入自定义平台。
- 平台热度：必填，使用 0 至 100 的数字，包含 0 和 100。
- 同一题材、同一平台的多份素材合并为一条定位结果。
- 汇总热度为相关有效素材平台热度的算术平均值。
- 定位结果同时显示有效素材数量和最近更新时间。
- 新增、修改、删除素材后，定位图在下一次请求时自动反映最新结果，不保存重复的汇总副本。

## 3. 数据模型

在 `materials` 表新增两个字段：

- `upload_platform`：字符串，最大 60 个字符，可建立普通索引。
- `platform_heat`：浮点数，取值范围 0 至 100，可建立普通索引。

数据库字段允许为空，原因是系统中已有历史素材和剧本。业务校验规则如下：

- 新上传的 `library_type=material` 记录必须同时提供两个字段。
- `library_type=script` 不要求提供这两个字段，并且不参与定位汇总。
- 历史素材字段为空时继续正常显示，并标记“平台信息待补充”；补充完整前不参与定位汇总。
- 素材编辑时可以补充或修改平台信息。校验编辑后的最终记录：两个字段必须同时有值或同时为空；已有完整平台信息时允许只修改其中一个字段。
- 平台名称保存前去除首尾空格；聚合时使用不区分大小写的规范键，展示采用已有记录中最近更新的名称写法。

迁移只新增字段和索引，不改写历史素材，不删除旧定位数据。

## 4. 素材上传与编辑

素材上传抽屉在题材选择之后增加：

1. 上传平台：可搜索、可创建选项的下拉框。
2. 平台热度：0 至 100 的数字输入框。

常用平台初始选项包含：番茄小说、七猫、起点中文网、晋江文学城、纵横中文网、抖音、快手、小红书、微信公众号、知乎。用户可以直接录入其他平台。

一次批量上传多份文件时，本次选择的平台和热度应用到全部文件。服务端仍逐文件返回成功或失败结果。

素材详情和编辑抽屉展示并允许修改这两个字段。素材列表可显示平台与热度，并增加上传平台筛选；从定位图进入素材库时自动带入题材和平台两个筛选条件。

## 5. 定位汇总

新增只读定位汇总接口：

`GET /api/genre-positioning`

支持参数：

- `genre_module_id`
- `upload_platform`
- `heat_min`
- `heat_max`

接口只统计满足以下条件的记录：

- `library_type=material`
- 未删除
- 题材有效且未删除
- `upload_platform` 非空
- `platform_heat` 非空且处于 0 至 100

按 `genre_module_id` 与规范化后的 `upload_platform` 分组，返回：

- `genre_module_id`
- `genre_name`
- `theme_color`
- `upload_platform`
- `average_heat`：保留一位小数
- `material_count`
- `latest_updated_at`

热度范围筛选作用于聚合后的 `average_heat`。接口直接聚合当前素材数据，不向旧 `genre_metrics` 表写入同步副本，因此不存在上传成功但定位数据遗漏或重复的问题。

## 6. 题材定位图页面

页面标题调整为“题材平台热度图”，说明文字明确数据来自素材库自动汇总。

保留的筛选项：

- 题材
- 上传平台
- 平均热度范围

保留“图表 / 表格”切换。

图表使用 ECharts 横向平台热度排行：

- 横轴为平均热度，范围固定为 0 至 100。
- 每一条数据代表一个“题材 + 平台”组合。
- 颜色使用题材主题色。
- 标签显示题材、平台、平均热度和素材数量。
- 数据较多时使用 ECharts `dataZoom` 纵向滚动，不压缩文字或缩小字号。
- tooltip 使用 ECharts `richText` 纯文本模式，避免把平台或题材名称作为 HTML 写入页面。
- 点击数据进入素材库，并自动按题材与上传平台筛选。

表格只显示：

- 题材
- 上传平台
- 平均热度
- 素材数量
- 最近更新时间
- 查看素材

页面移除频道、周期、平均年龄、年龄层级、学历层级、用户占比、趋势、重点、样本量、数据来源，以及手工新增、编辑、删除、导入、模板下载和导出定位数据的入口。

顶部摘要调整为：定位组合数、覆盖题材数、覆盖平台数、整体平均热度。整体平均热度按所有参与汇总的有效素材直接计算，避免题材平台组合的素材数量不同造成偏差。

## 7. 旧定位数据兼容

现有 `genre_metrics` 表及历史数据暂时保留，避免破坏已有数据库和备份兼容性，但新页面不再读取或修改它们。原有定位数据管理接口暂时保留为兼容接口，不在界面暴露。

后续确认不再需要历史定位数据后，可以在单独的数据清理版本中归档或删除；本次不执行破坏性清理。

## 8. 校验与错误处理

- 素材上传缺少上传平台：返回 422，并提示“请选择或输入上传平台”。
- 素材上传缺少平台热度或超出 0 至 100：返回 422，并提示正确范围。
- 素材编辑后只有平台或只有热度：返回 422，要求成对填写。
- 定位页没有有效素材时显示空状态，引导用户先上传或补充素材平台信息。
- 自定义平台去除首尾空格后为空时拒绝保存。

## 9. 测试范围

后端至少覆盖：

- 素材上传缺少平台或热度时拒绝。
- 0 和 100 两个边界值可保存，超出范围时拒绝。
- 剧本上传不强制平台字段且不进入汇总。
- 同题材同平台的多份素材正确计算平均热度和素材数量。
- 不同题材或不同平台分别汇总。
- 修改和删除素材后汇总立即更新。
- 历史空平台素材不参与汇总。
- 定位汇总筛选及素材平台筛选正确。
- 数据库迁移升级、降级和 Alembic metadata 检查通过。

前端至少覆盖：

- 素材上传表单必填校验和自定义平台。
- 素材详情、编辑与列表展示平台信息。
- 定位页面不再出现年龄、学历及手工定位数据入口。
- 图表和表格使用聚合接口数据。
- 点击定位结果携带题材和平台筛选跳转素材库。
- 历史素材显示“平台信息待补充”。

## 10. 不在本次范围

- 不为剧本库增加平台和热度字段要求。
- 不引入后台任务、消息队列或多线程同步。
- 不自动抓取第三方平台热度。
- 不删除旧 `genre_metrics` 表和历史数据。
- 不增加登录、权限、AI 生成或网页采集。
